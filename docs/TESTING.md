# Перевірки змін

Після розпакування змін у корінь робочого дерева проєкту виконайте з кореня репозиторію:

```bash
./mvnw clean test
```

Якщо в репозиторії немає Maven Wrapper, використайте `mvn clean test`.

## Що покривають додані/оновлені тести

- `SimulationSpeedCoordinatorTest` — валідацію та обробку зміни швидкості симуляції.
- `EditorProjectSessionCoordinatorTest` — вибір швидкості під час активації проєкту, зокрема fallback до значення за замовчуванням.
- `MainMenuViewTest` — актуальний контракт дій налаштування мови.
- `MapPresentationWorkflowLifecycleTest` — наскрізний сценарій перемикання проєкту; виклик конструктора координатора має відповідати новій сигнатурі без `DoubleSupplier` швидкості попереднього проєкту.

Повний Maven-набір у середовищі підготовки архіву не запускався, тому результати тестів не заявляються як успішні. Запустіть команду вище локально та перевірте її фактичний результат.
